Frequently Asked Questions

Everything you need to know

Does my data get uploaded to an external server?
No. In the default Free and Pro modes, StepSheet is 100% local-first. All parsing, formula execution, and charting happens entirely inside your web browser's JavaScript V8 engine or native desktop app. Sensitive spreadsheet data never leaves your computer.
Do I need a heavy backend server to use StepSheet?
No server is required. You can run StepSheet by opening the single-file HTML bundle or installing the Tauri desktop app without any background server processes. The optional FastAPI + DuckDB backend is only needed for Enterprise teams processing millions of rows simultaneously.
Can I export my pipeline back to real Excel formulas?
Yes! When exporting to Excel (.xlsx), StepSheet writes actual dynamic Excel formulas (like =XLOOKUP() and =IF()) rather than static computed values, so your colleagues can inspect and edit them in standard Microsoft Excel.
How does the Enterprise / Cloud Sync Tier work?
The Enterprise Tier deploys via Docker on Render or Railway, backed by Supabase PostgreSQL for connection-pooled storage and DuckDB for 4GB vectorized query execution. It provides multi-tenant team workspaces, SOC2-compliant audit trails, and deep-link sync into desktop apps.
